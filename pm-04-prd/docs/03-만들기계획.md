# 만들기 계획 · 내 지역 학교 커리큘럼

> 대상 기능: **지역 필터 선택 및 기본 지역 저장**  
> 기준 문서: [02-PRD.md](file:///c:/Users/현지/Desktop/pm-01-setup/pm-04-prd/docs/02-PRD.md)  
> 제외 항목: 서버 저장, 사용자 로그인 (브라우저 `localStorage` 활용)

---

## 4단계 실행 계획

### 1단계: 화면 상단 지역 선택 드롭다운 및 버튼 UI 배치 · 완료 (2026-10-04)
- **만드는 것**:
  - 화면 상단(학년 필터 위)에 어울리는 지역 필터 바 UI 추가
  - '시/도' 선택 드롭다운 (예: 서울특별시, 경기도 등)
  - '시/군/구' 선택 드롭다운 (시/도 선택에 따라 동적 변경: 강남구, 송파구, 서초구 등)
  - **[내 지역으로 저장]** 버튼 및 **[필터 해제]** 버튼
  - 안내 메시지 노출 영역 (토스트 알림)
- **확인하는 방법**:
  - 브라우저를 열었을 때 상단에 지역 드롭다운과 버튼들이 기존 다크 테마 디자인과 자연스럽게 어우러져 표시되는지 확인
  - '시/도'를 변경했을 때 '시/군/구' 항목이 맞게 바뀌는지 확인

---

### 2단계: 지역 선택에 따른 학교 커리큘럼 데이터 필터링 연동
- **만드는 것**:
  - 선택한 지역(시/도, 시/군/구)에 속한 학교의 평가 데이터만 화면에 걸러내는 필터링 로직
  - 지역 필터 적용 시 상단 통계(KPI), 역량 랭킹, 그리고 하단 '학교별 국어 수행평가 계획' 테이블이 해당 지역 데이터로 갱신
  - [필터 해제] 클릭 시 전체 학교 데이터로 즉시 복귀
- **확인하는 방법**:
  - 드롭다운에서 '서울특별시' - '송파구'를 선택했을 때, 송파구 관내 학교(가락중, 서울송파초 등)만 화면에 나타나는지 확인
  - [필터 해제] 버튼을 누르면 다시 전체 학교 목록으로 돌아오는지 확인

---

### 3단계: [내 지역으로 저장] 버튼 및 안내 문구 동작 (`localStorage`)
- **만드는 것**:
  - **[내 지역으로 저장]** 버튼 클릭 이벤트 처리
  - 브라우저 로컬 저장소(`localStorage`)에 선택한 기본 시/도, 시/군/구, 저장 일시 저장
  - 화면에 *"내 지역으로 저장되었습니다"* 안내 문구(토스트 알림) 노출
- **확인하는 방법**:
  - 지역을 고르고 **[내 지역으로 저장]** 버튼을 클릭했을 때 화면에 *"내 지역으로 저장되었습니다"* 알림이 뜨는지 확인
  - 개발자 도구(F12)의 Application > Local Storage에 해당 지역 정보가 기록되는지 확인

---

### 4단계: 브라우저 새로고침 및 재접속 시 자동 유지 (성공 기준 점검)
- **만드는 것**:
  - 대시보드 접속(초기 로딩) 시 `localStorage`에 저장된 기본 지역이 있는지 감지하는 로직
  - 저장된 기본 지역이 있으면 드롭다운 값을 자동으로 채우고, 시작부터 해당 지역 커리큘럼 화면으로 바로 노출
- **확인하는 방법**:
  - **성공 기준 ① 확인**: 지역을 저장한 뒤 브라우저 새로고침(F5)을 눌렀을 때, 3초 이내에 저장한 지역 목록이 유지되어 뜨는지 확인
  - **성공 기준 ② 확인**: 브라우저 창을 완전히 닫았다가 다시 열었을 때도 마지막 저장 지역 필터 화면이 3초 안에 뜨는지 확인
