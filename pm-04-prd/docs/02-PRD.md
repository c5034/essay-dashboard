# PRD · 내 지역 학교 커리큘럼

> 4회차 · 2026-09-29 작성 · 5회차부터 클로드 코드가 이 문서를 읽고 만든다
> 갈 길 · B 대시보드 키우기

## 한 줄 소개
매주 수업 계획을 세우는 학원 강사를 위해, 담당 지역 학교들의 교육과정을 접속하자마자 바로 모아볼 수 있게 해 준다.

## 문제
특정 지역 학원에서 교육과정을 연구하는 학원 강사가 매주 수업 계획을 세울 때, 매번 전체 지역과 학교를 다시 찾아야 해서 담당 지역 학교들의 교육과정을 바로 확인하기 어렵다.

## 대상
담당 지역 학교들의 교육과정을 매주 찾아보고 수업 계획에 반영하는 학원 강사

## 출발점 (3회차)
- 3회차에 만든 것 · 전국 학교 및 교육청 교육과정 대시보드
- 아쉬웠던 점 ·
  1. 내가 근무하는 지역의 학교 위주로 커리큘럼을 볼 수 없음
  2. 지역을 고를 수 있으면 좋겠음

## 이번에 만들 기능
**지역 필터 선택 및 기본 지역 저장** · 지역(시/도, 시/군/구)을 선택해 "내 지역 저장"을 누르면 접속 시 해당 지역 학교 커리큘럼이 첫 화면에 자동 노출되는 기능

### 동작 순서
1. 사용자가 화면 상단의 "지역 선택" 드롭다운 목록(시/도, 시/군/구)을 본다
2. 원하는 지역(예: 서울시 강남구)을 고르고 "내 지역으로 저장" 버튼을 누른다
3. 화면에 "내 지역으로 저장되었습니다" 안내 문구가 뜨고, 해당 지역 학교들의 교육과정 목록만 화면에 나타난다
4. 브라우저를 새로고침하거나 다시 접속해도 내가 저장한 지역의 학교 교육과정이 첫 화면에 바로 보인다
5. 다른 지역을 보고 싶을 때는 언제든 드롭다운을 다시 고르고 "지역 변경" 또는 "필터 해제"를 누른다

## 저장할 것 (6회차)
- 기본 시/도 · 서울특별시
- 기본 시/군/구 · 강남구
- 설정 저장 일시 · 2026-09-29 14:00

## 기록할 행동 (7회차)
- "내 지역으로 저장" 버튼을 누를 때 1번
- "필터 해제" 또는 "지역 변경"을 누를 때 1번

## 성공 기준 (8회차)
기한 · 10월 4일 5회차 수업 끝
1. 내가 브라우저에서 지역을 고르고 "내 지역으로 저장"을 누른 뒤, 새로고침해도 해당 지역 학교 교육과정 목록이 3초 안에 유지되어 뜬다
2. 내가 브라우저를 완전히 닫았다가 다시 열었을 때, 마지막으로 저장한 지역 필터가 적용된 화면을 3초 안에 본다
