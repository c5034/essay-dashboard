문제

특정 지역 학원에서 교육과정을 연구하는 학원 강사가 매주 수업 계획을 세울 때, 매번 전체 지역과 학교를 다시 찾아야 해서 담당 지역 학교들의 교육과정을 바로 확인하기 어렵다.

대상

담당 지역 학교들의 교육과정을 매주 찾아보고 수업 계획에 반영하는 학원 강사
학원 강사 교육과정 연구 매주 계획 수립

3회차 출발점에서 이번에 만들 기능으로 5회차

출발점 · 3회차
전국 학교 및 교육청 교육과정 대시보드
아쉬웠던 점

· 지역을 고를 수 있으면 좋겠음

이번에 만들 기능
지역 필터 선택 및 기본 지역 저장
지역(시/도, 시/군/구)을 선택해 "내 지역 저장"을 누르면 접속 시 해당 지역 학교 커리큘럼이 첫 화면에 자동 노출되는 기능

동작 순서 · 보이는 것, 누르는 것, 생기는 것

  1. 사용자가 화면 상단의 "지역 선택" 드롭다운 목록(시/도, 시/군/구)을 본다
  2. 원하는 지역(예: 서울시 강남구)을 고르고 "내 지역으로 저장" 버튼을 누른다
  3. 화면에 "내 지역으로 저장되었습니다" 안내 문구가 뜨고, 해당 지역 학교들의 교육과정 목록만 화면에 나타난다
  4. 브라우저를 새로고침하거나 다시 접속해도 내가 저장한 지역의 학교 교육과정이 첫 화면에 바로 보인다
  5. 다른 지역을 보고 싶을 때는 언제든 드롭다운을 다시 고르고 "지역 변경" 또는 "필터 해제"를 누른다
